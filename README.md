
# INFRASLIM – Kalkulator prihodkov in stroškov

## Opis projekta
INFRASLIM Kalkulator je preprosta spletna aplikacija,
namenjena izračunu mesečnega finančnega rezultata
fitnes in wellness studia.

Projekt je izdelan v okviru predmeta
Razvoj programske opreme (RPO).

## Uporabljene tehnologije
- HTML5 – struktura aplikacije
- CSS3 – oblikovanje uporabniškega vmesnika
- JavaScript – izračuni in preverjanje vnosov
- Git – nadzor različic
- GitHub – gostovanje in sodelovanje

## Funkcionalnosti
- Vnos mesečnih prihodkov
- Vnos mesečnih stroškov
- Izračun razlike med prihodki in stroški
- Prikaz pozitivnega, negativnega ali ničelnega rezultata
- Preverjanje veljavnosti podatkov

## Zagon aplikacije
1. Prenesemo ali kloniramo repozitorij.
2. Odpremo mapo projekta.
3. Datoteko index.html odpremo v spletnem brskalniku.
4. Vnesemo prihodke in stroške.
5. Kliknemo gumb Izračunaj rezultat.

## Načrtovane izboljšave
- Dodajanje kategorij stroškov
- Pregled prihodkov po storitvah
- Shranjevanje podatkov
- Mesečna statistika
